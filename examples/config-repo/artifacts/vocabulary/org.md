# Example vocabulary

Teaches dictation the names this organization uses. Every table row with
a **Term** is read; headings and text like this are ignored.

- **Term**: the written form. It goes into the engine's hint when relevant.
- **Heard as**: quoted forms replaced by the term automatically. List only forms
  that are never meant literally.
- **Notes**: for people. The engine takes text only.

| Term | Heard as | Notes |
|---|---|---|
| Acme Cloud | "acne cloud" | the product |
| PLATFORM | | Jira project key |
