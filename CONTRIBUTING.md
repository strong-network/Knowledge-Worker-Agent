# Contributing

Thank you for your interest in Knowledge Worker Agent.

It's developed in an internal Citrix repository and published here at intervals, so this
repository doesn't accept contributions. A pull request can't be merged, because the next
release replaces the repository's contents.

You're welcome to use, change, and redistribute the code under the Apache License 2.0. See
[LICENSE](LICENSE) and [NOTICE](NOTICE). To build and test it, see the [README](README.md#build-and-test).

To report a security vulnerability, follow [SECURITY.md](SECURITY.md). Don't open a public issue
or pull request for it.

## Maintainers

Knowledge Worker Agent is maintained by the Citrix SecurSpaces team. It isn't a supported Citrix
product, and Citrix doesn't provide support for it.
